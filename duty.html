탕정삼성어린이집 당직표 생성기

문의사항: 김혜인 교사 ·
화면 사용 가능 · 공용 저장소 연결 확인 중...

1. 기준 월 선택

선택한 월을 기준으로 연차 목록을 조회하고 당직표 생성 대상 월을 설정합니다.

2. 저장된 당직표 조회

이 아래 설정과 목록은 선택한 기준 월을 중심으로 표시됩니다.

3. 교사명단

형식: 연령, 반, 이름, 신입여부 / 예: 만1세, 햇빛반, 김교사, 신입

4. 연차 입력

날짜를 선택하면 교사 선택창이 팝업으로 열립니다. 등록·삭제와 동시에 공용 저장소에 자동 저장됩니다.

연차 교사 선택

5. 공휴일 / 제외일 입력

6. 기간별 개별 당직 제한

특정 교사가 일정 기간 동안 오전, 오후, 탄력근무 또는 전체 당직을 하지 않도록 설정할 수 있습니다. 시작일과 종료일을 같은 날짜로 선택하면 하루만 제한됩니다.

7. 교사별 당직 시작일

신입·중도입사 교사가 해당 월의 특정 날짜 이후부터 당직에 배정되도록 설정합니다. 이 설정은 선택한 월에만 적용되며 다른 달의 당직표에는 영향을 주지 않습니다. 해당 월의 실제 당직 가능 기간에 비례하여 총시간·횟수도 자동 조정됩니다.

8. 당직표 생성

위에서 선택한 기준 월의 연차·공휴일·당직 제한·당직 시작일을 반영하여 당직표를 생성합니다.

배정 우선순위 안내

같은 연령의 당직을 가장 우선하고, 다음으로 영아반 교사는 영아 당직·유아반 교사는 유아 당직을 우선합니다. 동일한 당직 반과 놀이터 시건이 한 교사에게 반복되지 않도록 분산하며, 1시간·1.5시간·2시간 당직도 각 교사에게 고르게 돌아가도록 배정합니다. 탄력근무는 추가 근무시간이 아니므로 시간으로 계산하지 않고 횟수로만 관리합니다. 탄력은 월 최대 3회, 같은 주 1회까지만 가능하며 직전 근무일과 연속 배정하지 않습니다. 같은 반에서 연차자가 있는 날에는 그 반 교사는 탄력에 배정하지 않고, 같은 반 교사 2명이 같은 날 동시에 탄력에 배정되지 않습니다. 연차 다음 날에는 당직을 배정하지 않습니다.
